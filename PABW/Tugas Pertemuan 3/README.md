# ExploreTrip

ExploreTrip adalah website sederhana yang dibuat untuk memperkenalkan berbagai destinasi wisata dan paket perjalanan.

## Destinasi Wisata

Website ini menampilkan lima destinasi wisata, yaitu:

- Cipeundeuy Endah
- Curug Ibun Pelangi
- Curug Muara Jaya
- Guci
- Situmpuk Hill

## Fitur

- Hero section dengan slideshow gambar otomatis
- Daftar lima destinasi wisata beserta gambar dan deskripsi
- Lima paket wisata yang dilengkapi gambar, deskripsi, dan harga
- Video untuk memperkenalkan destinasi wisata
- Navigasi menu Home, Destinations, Packages, dan Video
- Responsive design untuk menyesuaikan tampilan dengan ukuran layar

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
